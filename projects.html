Neatnet
demo coming soon GitHub

A folder you've been dumping files into for years is faster to ignore than to fix, so Neatnet sorts it for you. It scans the folder, proposes a full reorganization plan, and lets you drag files around to adjust it before anything moves on disk. Nothing is applied until you confirm, and it runs on Claude in the cloud or entirely offline with a local model, so a messy folder never has to leave your machine.

Personal Finance App
demo coming soon GitHub

Your spending is spread across bank and card statements that are tedious to add up by hand, so this app does the tallying for you. Upload your CSVs and it sorts every transaction into one of 11 spending categories using a fine-tuned BERT model backed by rule-based patterns, then shows where the money actually went on an interactive dashboard. The result is expense tracking and budgeting insights built from your real statements, not manual guesswork.

ATP Tennis Match Predictor
demo coming soon GitHub

Picking who wins a tennis match means juggling rankings, surface, recent form, and history that rarely point the same way, so this predictor weighs it all for you. Choose an ATP matchup and it returns each player's win probability from an ensemble of LightGBM models built on rank, age and height gaps, surface, recent form, head-to-head priors, and a Bradley-Terry skill rating. You can run it from the command line, in Docker, or through a FastAPI web interface.

Car Racing with Reinforcement Learning
demo coming soon GitHub

An AI given nothing but a 2D racetrack and a reward signal has to discover how to drive from scratch, and this project lets you watch it happen. It trains agents on Gymnasium's CarRacing environment with two different learning styles, value-based (DQN) and policy-gradient (PPO), so you can compare how each one improves lap after lap. Saved agents can be replayed to see what the learned policy actually does behind the wheel.
